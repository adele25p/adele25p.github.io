# Documentation — Portfolio Adèle
Ce dossier regroupe toute la documentation de cadrage du projet.

**Version** : v1.0

## Contenu

```
docs/
├── README.md              # ce fichier
├── design-brief.md
├── tech-spec.md
├── conventions.md

├── assets/

│   ├── inspiration/       # images d'inspiration

    └── ...                # fichiers ADR
```

## Documents de cadrage

1. **[design-brief.md](./design-brief.md)** — le pourquoi et le pour qui. 

Présente le contexte du projet, le public cible, le périmètre et la direction visuelle.

2. **[tech-spec.md](./tech-spec.md)** — le quoi. 

Présente la stack technique, la structure de l'interface, le contenu des pages et la structure des données.

3. **[conventions.md](./conventions.md)** — le comment. 

Présente les conventions de nommage, de structuration et d'organisation du projet.

## Document transversal

- **[project-notes.md](./project-notes.md)** — le pense-bête. 

Présente les idées d'évolutions futures, les questions encore ouvertes et les notes diverses du projet.

## Architecture Decision Records (ADR)

- **[adr/README.md](./adr/README.md)** — index des ADR.

Contient la liste des décisions d'architecture prises pour le projet, avec un lien vers chaque ADR détaillé. Chaque ADR est un document autonome qui explique le contexte, les options considérées, la décision prise et les raisons de cette décision.
